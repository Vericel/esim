# ff README 与 User Guide 设计

日期：2026-08-02

## 目标

将当前 README 收缩为面向首次使用者的简要入口，并提供一份详细的中文
HTML User Guide。两份文档都只描述已实现的 ff 行为，以
`docs/requirements/ff.md` 为权威内容来源。

## 交付物

### README.md

README 仅保留：

1. ff 的一段简介。
2. Python 版本和 wheelhouse 离线安装命令。
3. 一个不带选项的最小使用示例。
4. 一个带输出和预定义宏的常用示例。
5. 指向 HTML User Guide 和需求契约的链接。

README 不再承载 Python 引擎 API、日志矩阵、退出码或 filelist 细节规则。

### docs/user/ff-user-guide.html

User Guide 是可直接用浏览器打开的单文件中文 HTML：

- CSS 全部内嵌，不引用字体、图标、脚本或任何网络资源。
- 宽屏使用左侧粘性导航与右侧正文，窄屏自动改为单栏。
- 使用语义化 HTML，所有章节都有稳定的内部锚点。
- 不使用 JavaScript，避免产生额外运行时行为和维护负担。

## 内容架构

User Guide 按使用任务而不是实现模块组织：

1. ff 是什么，以及第一版的范围边界。
2. 安装和快速开始。
3. CLI 命令格式、输出、宏、日志与退出码。
4. 条件指令及非活动分支的处理。
5. `-f/-F` 嵌套 filelist 与路径基准。
6. 环境变量语法、递归展开和失败情况。
7. 注释、路径条目、透传选项和不支持的语法。
8. 绝对路径输出、symlink 注释、权限和原子替换。
9. 日志组合、错误信息、source chain 和常见排错。
10. 规则速查表与明确的不支持项。

每个主要规则组优先通过“输入 filelist—执行命令—展平结果”三段式示例
说明。示例中的路径和宏名与 README 保持一致。

## 视觉与可用性

- 整体是工程手册风格，使用高对比中性色和单一强调色。
- 代码块、提示、警告、输出和错误示例有明确的视觉区分。
- 正文宽度限制在适合阅读的范围，代码块允许水平滚动。
- 颜色不是区分信息类型的唯一手段，同时使用文字标签。
- 打印时隐藏左侧导航，保留正文和 URL 可读性。

## 范围边界

- User Guide 面向 ff CLI 使用者，不介绍 esim TC YAML 字段。
- Python 引擎 API 不在 User Guide 主体中展开。
- 不新增、改变或推测 ff 行为。
- 不引入文档生成器、外部 CSS 框架或 JavaScript 依赖。

## 验证方案

1. 对照 `docs/requirements/ff.md` 逐类核对 HTML 章节和示例，保证没有丢失重要用户规则。
2. 解析 HTML，验证标题、章节 ID、内部链接和重复 ID。
3. 扫描 `src`/`href` 与 CSS，确认没有 HTTP(S) 或本地附加资源依赖。
4. 以桌面宽度和窄屏宽度分别渲染，检查导航、正文、代码块和打印样式。
5. 检查 README 链接目标存在，并保持 README 只包含简介、安装和基础用法。
